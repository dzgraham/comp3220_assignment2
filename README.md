# comp3220_assignment2 - Maze Solver
    Assignment 2 for Daniel Graham 620171166

Requirements:
    Python Version: Python 3.8+
    Libraries: Python Standard Library (turtle and tkinter are built-in and explicitly imported) 

Scripts
    maze_solver.py - defines maze and algorithm logic
    visualize.py - runs and displays algorithm

To run program, run the visualize.py script.
In terminal, type and enter, "python visualize.py"

Switching and running algorithms. Click the number associated with each algorithm.
    1 = BFS    2 = DFS    3 = A*    4 = Greedy Best-First (added algorithm)

Click 'R' or 'r' to reset the maze
    R = reset

visualize.py also prints the algorithm statistics to the console after each run
    nodes expanded, path length, path cost    

Creative enhancements:
    Additional Algorithm: Greedy Best-First Search
